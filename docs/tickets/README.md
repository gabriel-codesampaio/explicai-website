# Tickets

Fila de trabalho da landing. Formato e ciclo de vida: skill `tickets` do plugin [explicai-workflow](https://github.com/gabriel-codesampaio/explicai-workflow).

Prioridade: **P0** atinge quem lê o resultado final; **P1** engana ou bloqueia; **P2** incomoda, há como contornar; **P3** acabamento.

Ticket fechado (feito ou descartado) vai para `fechados/` com `git mv`.
